# dsh-ai

Test repository for the dsh-superagent prototype: a proactive coding agent
for one GitHub repository, packaged as a DeepSeek Harness bundle.

## Usage

From an allowed GitHub account, comment `@xiaoyeziyinxing <request>` on an
Issue. The agent opens a work item, works in its own session and directory,
and answers in the original conversation — for example with a pull request.
